# Changelog - 2026-10-18

## ARDOR builds on the IGNIS 0.2.2-12 chain

<Badge type="warning" text="Behavior Change" />

**In one line.** ARDOR's four packages now require the IGNIS prerelease chain published on 2026-10-18, so an application keeps one IGNIS line and one copy of each package.

```bash
bun add @venizia/ardor @venizia/ignis-kernel@next @venizia/ignis-connectors@next @venizia/ignis-inversion@next @venizia/ignis-filter@next @venizia/ignis-helpers@next
```

## What changed

- **The peer floors moved.** `@venizia/ignis-kernel` and `@venizia/ignis-connectors` need `^0.2.2-12`, `@venizia/ignis-helpers` `^0.2.2-7`, and `@venizia/ignis-inversion` and `@venizia/ignis-filter` `^0.2.2-4`. All of them stay below 0.3.0.
- **Nothing in the source changed.** The pins move the toolchain only: `@venizia/dev-configs` 0.3.1-2 and `@venizia/vulcan` 0.2.0-7.

## Who is affected

- **An application on an older IGNIS prerelease.** Move every `@venizia/ignis-*` package to the versions above, and together: a floor below them fails to resolve, and one package a release behind another installs without a warning.
- **Contributors to the ARDOR repository.** Run `bun install --no-cache` after you pull: Bun can hold an older registry listing for a few minutes after a publish.
