# Changelog - 2026-10-24

## ARDOR 0.4.0 follows IGNIS 0.4.0

<Badge type="warning" text="Breaking Change" />

**In one line.** All four ARDOR packages are published at 0.4.0 and peer on IGNIS 0.4.0, as ARDOR 0.3.0 followed IGNIS 0.3.0; the code of the packages is the code of 0.3.7.

```bash
bun add @venizia/ardor
```

## What changed

- **One version, on the IGNIS line.** ARDOR and IGNIS share a minor: ARDOR 0.4.x pairs with IGNIS 0.4.x. IGNIS 0.4.0 is a minor because it removed the formatter exports of `@venizia/dev-configs` and the ESLint Prettier rule.

| Package | Version | IGNIS peers |
|---------|---------|-------------|
| `@venizia/ardor` | 0.4.0 | `^0.4.0`: `ignis-kernel`, `ignis-helpers`, `ignis-inversion`, `ignis-filter`, `ignis-connectors` (optional) |
| `@venizia/ardor-kernel` | 0.4.0 | `^0.4.0`: the same five, `ignis-connectors` optional |
| `@venizia/ardor-react`, `@venizia/ardor-admin` | 0.4.0 | `^0.4.0`: `ignis-kernel`, `ignis-helpers`, `ignis-inversion`, `ignis-filter` |

- **The code is the code of 0.3.7.** Twenty-two source files of the packages changed since 0.3.7, only in layout (a single arrow parameter lost its parentheses, a JSX closing bracket moved); transpiled, the old and the new text are identical. What changed in the packages is their manifests: the peer ranges, and the order of their keys.
- **Required runtime variables.** An app made from the preset can list the variables it cannot run without in `APP_REQUIRED_ENV`, and its container stops at start naming each one that is missing. See [A container stops when a required variable is missing](./2026-10-23-runtime-config-required-env).
- **No formatter config in a generated app.** The app preset no longer ships `.configs/formatters/oxfmt.config.mts`; `devz lint` formats with `bun fmt` from the `bunfig.toml` that `vulcan init` writes. See [No project keeps a formatter config any more](./2026-10-23-no-formatter-config).
- **Floors.** A project made from the preset needs VULCAN 0.3.12 or newer and `@venizia/dev-configs` 0.4.0 or newer.

## Who is affected

- **An application on ARDOR 0.3.x.** Move the four ARDOR packages and every `@venizia/ignis-*` package to 0.4.0 in one change. A `^0.3.6` IGNIS range does not match 0.4.0, so a package left behind installs a second copy of its siblings.
- **A library that peers on ARDOR or IGNIS.** Move its peer ranges with them.
- **An app already generated from the preset.** It keeps working on ARDOR 0.4.0. To format with `bun fmt`, follow [No project keeps a formatter config any more](./2026-10-23-no-formatter-config).
- **A new project.** Start from the preset.

## Breaking changes

> [!WARNING]
> Applications and libraries that peer on IGNIS 0.3.x cannot take ARDOR 0.4.0: the peer ranges moved to `^0.4.0`.

**Before:**

```text
@venizia/ardor 0.3.7        peers @venizia/ignis-kernel ^0.3.6
```

**After:**

```text
@venizia/ardor 0.4.0        peers @venizia/ignis-kernel ^0.4.0
```
