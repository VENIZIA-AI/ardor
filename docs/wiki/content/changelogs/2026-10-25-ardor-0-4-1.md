# Changelog - 2026-10-25

## ARDOR 0.4.1 follows IGNIS 0.4.1

<Badge type="warning" text="Breaking Change" />

**In one line.** All four ARDOR packages are published at 0.4.1 and peer on IGNIS 0.4.1. Every earlier ARDOR logs the Authorization token and the sign-in password to the browser console on each request; 0.4.1 is the first version without that.

```bash
bun add @venizia/ardor
```

## What changed

| Package | Version | IGNIS peers |
|---------|---------|-------------|
| `@venizia/ardor` | 0.4.1 | `^0.4.1`: `ignis-kernel`, `ignis-helpers`, `ignis-inversion`, `ignis-filter`, `ignis-connectors` (optional) |
| `@venizia/ardor-kernel` | 0.4.1 | `^0.4.1`: the same five, `ignis-connectors` optional |
| `@venizia/ardor-react`, `@venizia/ardor-admin` | 0.4.1 | `^0.4.1`: `ignis-kernel`, `ignis-helpers`, `ignis-inversion`, `ignis-filter` |

- **No secret in the console.** See [The fetcher no longer logs secrets, and four request bugs are fixed](./2026-10-24-node-fetcher-fixes). Rotate any token or password that a console, a log collector or a bug report may have captured on 0.4.0 or older.
- **Fixes and a split network service.** See [Correctness fixes in the kernel, the admin and the hooks](./2026-10-25-correctness-fixes) and [The network service is split into small parts, and its types are closed](./2026-10-25-network-service-split): list requests send `skip` only, `ISendParams` and `IApplicationInfo` are closed, `refreshToken` answers `Promise<boolean>`, and the parse utilities and `parseQueryString` are removed.
- **IGNIS helpers replace three forks.** The fetch transport, the query string and the socket client come from `@venizia/ignis-helpers` 0.4.1. The `./socket-io` sub-paths of `@venizia/ardor-kernel` and `@venizia/ardor` are removed, and `socket.io-client` is no longer a peer of ARDOR: hand `module: { io }` to `SocketIOClientHelper` from your own import.

## Who is affected

- **Every application on ARDOR 0.4.0 or older.** Move the four ARDOR packages and every `@venizia/ignis-*` package to 0.4.1 in one change, then rotate what the console may have shown.
- **An application that imports a removed export or a `./socket-io` sub-path.** Import the IGNIS helper instead; [the network service entry](./2026-10-25-network-service-split) lists every removed name.
- **A library that peers on ARDOR or IGNIS.** Move its peer ranges with them.

## Breaking changes

> [!WARNING]
> An application on `@venizia/ignis-helpers` 0.4.0 cannot take ARDOR 0.4.1: the peer ranges moved to `^0.4.1` because the fetch transport, the query string options and the socket client now come from it.

**Before:**

```text
@venizia/ardor 0.4.0        peers @venizia/ignis-helpers ^0.4.0
```

**After:**

```text
@venizia/ardor 0.4.1        peers @venizia/ignis-helpers ^0.4.1
```
