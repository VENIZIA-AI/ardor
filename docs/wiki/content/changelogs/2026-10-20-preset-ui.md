# Changelog - 2026-10-20

## The generated app is one styled page

<Badge type="tip" text="Enhancement" />

**In one line.** An app made by `vulcan init --preset ardor` no longer shows plain HTML pages: it shows the ARDOR logo, the app name and the message of the backend's `GET /api/hello` in one card, in a light and a dark theme.

## What changed

- **One page.** The page is a card on a soft wash of the brand gradient: the logo, the app name, and what the backend answers to `GET /api/hello`. The product list and its form are gone from the preset.
- **Three states.** A placeholder while the request runs, the message, and, when the backend is not reachable, one line that says so with the command that starts it (`bun run server:dev`) and a button to try again.
- **The call goes through ARDOR.** It uses the data provider's `send`, so it has the `/api` prefix and the headers of every request of the app, not a raw `fetch`.
- **Light and dark.** The colours are tokens in `src/themes/index.css` and follow the system's light or dark preference; there is no toggle.
- **Components you own.** The shadcn-style components (`button`, `card`) are copied into `src/components/shadcn/`. To add more with the shadcn CLI, run `bunx shadcn init` first, which writes its own `components.json`.
- **Tailwind CSS v4 in one CSS file.** There is no `tailwind.config` file. The only Vite-specific line is the `tailwindcss()` plugin in `.configs/builders/vite.config.mts`.
- **A browser check.** The preset smoke opens the app in headless Chrome and checks the app name and the message, that the stylesheet applies, that dark differs from light and that the console has no error, then makes `/api/hello` fail and checks the unreachable state.

## Who is affected

- **An app already generated from the preset.** Nothing changes. Copy the files you want from a new app.
- **A new app.** It has the hello page. Replace it with your own; the components stay yours.
