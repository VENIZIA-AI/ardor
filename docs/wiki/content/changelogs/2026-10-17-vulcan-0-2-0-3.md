# Changelog - 2026-10-17

## VULCAN 0.2.0-3 and the atlas source filter

<Badge type="tip" text="Enhancement" />

**In one line.** ARDOR pins `@venizia/vulcan` 0.2.0-3, and the atlas `search` tool takes a `source` to narrow a query to one project.

```bash
bun install
```

## What changed

- **`search` takes a `source`.** `ardor` or `ignis` narrows a query to one project, beside the `corpus` filter that picks the knowledge bundle, the wiki or the changelogs.
- **An unknown symbol is not an error.** The `symbol` tool answers `matches: []` with the `closest` names, so a typo such as `useInjectabl` points at `useInjectable`.

## Who is affected

- **Applications that use ARDOR.** No action needed.
- **Contributors to the ARDOR repository.** Run `bun install` after you pull.
