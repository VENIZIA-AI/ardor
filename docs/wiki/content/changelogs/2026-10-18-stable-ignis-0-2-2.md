# Changelog - 2026-10-18

## ARDOR 0.1.4 on stable IGNIS 0.2.2

<Badge type="warning" text="Behavior Change" />

**In one line.** Every `@venizia/ignis-*` peer of the four packages is `^0.2.2`, the stable range, instead of a `0.2.2-N` prerelease floor. This also replaces the earlier `0.2.2-9` and `0.2.2-12` prerelease peer floors.

```bash
bun add @venizia/ardor@latest @venizia/ignis-kernel@latest @venizia/ignis-inversion@latest @venizia/ignis-filter@latest @venizia/ignis-helpers@latest @venizia/ignis-connectors@latest
```

## What changed

- **The peers are `^0.2.2`.** `@venizia/ignis-kernel`, `@venizia/ignis-connectors`, `@venizia/ignis-helpers`, `@venizia/ignis-inversion` and `@venizia/ignis-filter` each need `^0.2.2` in whichever of the four packages declares them. Nothing in the source changed: this is the same code as 0.1.4-5.
- **The `latest` tag moves.** ARDOR 0.1.4 is the first stable release since 0.1.3, so `bun add @venizia/ardor` resolves it without `@next`.

## Who is affected

- **An application on an IGNIS prerelease (`0.2.2-N`).** `^0.2.2` does not match a prerelease, so the package manager warns about the peer. Move the `@venizia/ignis-*` packages to 0.2.2, together.
- **An application already on IGNIS 0.2.2.** No action beyond updating ARDOR.
