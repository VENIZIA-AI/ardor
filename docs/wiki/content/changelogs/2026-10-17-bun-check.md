# Changelog - 2026-10-17

## Type checking runs on bun check

<Badge type="tip" text="Enhancement" />

**In one line.** `make typecheck` (and so `make rebuild` and `make <pkg>`) and `make lint-scripts` type-check with `bun check`, and tsc only emits the JS and the declarations.

```bash
make typecheck-all   # bun check --no-pretty -p tsconfig.json, then the build program, per package
```

## What changed

- **`bun check` replaces `tsc --noEmit`.** It reports the same diagnostics, preset strictness included, on every CPU core.
- **tsc still builds.** `make build` emits `dist` with tsc and tsc-alias, as before.
- **Bun 1.4.3 is the floor.** The root `engines.bun` is `>=1.4.3`, and the release workflow runs Bun 1.4.3.

## Who is affected

- **Applications that use ARDOR.** No action needed.
- **Contributors to the ARDOR repository.** Upgrade to Bun 1.4.3 or later (`bun upgrade`).
