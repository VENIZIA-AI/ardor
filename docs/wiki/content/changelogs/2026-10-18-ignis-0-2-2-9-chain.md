# Changelog - 2026-10-18

## ARDOR builds on the IGNIS 0.2.2-9 chain

<Badge type="warning" text="Behavior Change" />

**In one line.** ARDOR's four packages now require the IGNIS prerelease chain published on 2026-10-18, so an application installs one IGNIS line and gets one copy of each package.

```bash
bun add @venizia/ardor @venizia/ignis-kernel@next @venizia/ignis-connectors@next
```

## What changed

- **The peer floors moved.** `@venizia/ignis-kernel` and `@venizia/ignis-connectors` need `^0.2.2-9`, `@venizia/ignis-helpers` `^0.2.2-6`, and `@venizia/ignis-inversion` and `@venizia/ignis-filter` `^0.2.2-3`. All of them stay below 0.3.0.
- **`@venizia/ignis-boot` 0.2.1-4 works with `artifacts()`.** Return `AutoArtifacts` from `@venizia/ignis-boot/auto`, or build with `IgnisArtifactsPlugin`, and the application registers its decorated classes without a generated file. See [Application](../references/application#without-a-generated-file-ignis-boot-auto).
- **Three kernel imports are type-only.** `Container`, `Socket` and five constants from `./constants` are imported with `type`, as the new lint preset requires. The compiled output does not change.

## Who is affected

- **An application on an older IGNIS prerelease.** Move every `@venizia/ignis-*` package to the versions above; a floor below them fails to resolve.
- **An application on IGNIS `latest` (0.2.1).** It cannot satisfy the floors. ARDOR already tracks the prerelease line, so this changes nothing new.
- **Contributors to the ARDOR repository.** Run `bun install --no-cache` after you pull: Bun can hold an older registry listing for a few minutes after a publish.
