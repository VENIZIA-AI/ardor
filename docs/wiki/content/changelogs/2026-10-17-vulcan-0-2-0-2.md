# Changelog - 2026-10-17

## VULCAN 0.2.0-2, docs-update and the D rules

<Badge type="tip" text="Enhancement" />

**In one line.** ARDOR pins `@venizia/vulcan` 0.2.0-2, and VULCAN's `docs-update` skill now updates the wiki by the D rules in `.agents/rules.md`.

```bash
bun install
bun x vulcan sync --prune   # links docs-update, removes the dead update-wiki link
```

## What changed

- **`docs-update` replaces `update-wiki`.** ARDOR's own skill is deleted. VULCAN's skill reads the wiki paths from the manifest and applies the docs rules of `.agents/rules.md`.
- **The wiki rules are a D group.** D-01 to D-04 say where a page goes, its house style, how it is wired into the sidebar and the section index, and which four gates must pass. They mean the same as in IGNIS. D-05 is ARDOR's: build the packages before the docs gates, because every `ts` fence compiles against `dist`.
- **The atlas keeps its name.** With IGNIS served beside this checkout, the server still names itself `ardor-atlas`, and a rebuild reaches the `symbol` tool without a restart.

## Who is affected

- **Applications that use ARDOR.** No action needed.
- **Contributors to the ARDOR repository.** Run `bun install`, then `bun x vulcan sync --prune` once, after you pull.
