# Changelog - 2026-09-24

## ARDOR 0.1.1, the first stable line on IGNIS 0.2.0

<Badge type="tip" text="Enhancement" />

**In one line.** `npm install @venizia/ardor` now installs a stable release: the line published under `next` as `0.1.1-4` moves to `latest` as `0.1.1`, with no code change.

## What changed

| Package | `next` | `latest` |
|---|---|---|
| `@venizia/ardor-kernel` | 0.1.1-4 | 0.1.1 |
| `@venizia/ardor-react` | 0.1.1-3 | 0.1.1 |
| `@venizia/ardor-admin` | 0.1.1-3 | 0.1.1 |
| `@venizia/ardor` | 0.1.1-4 | 0.1.1 |
| `@venizia/ardor-ui-kit` | 0.0.2-1 | 0.0.2 |

The code is the code of the prereleases: [2026-09-23](./2026-09-23-registration-by-hand-and-clean-install) and [2026-09-24](./2026-09-24-remote-repositories-and-relative-base-url) describe what it contains. Before this, `latest` pointed at the `0.1.1-0` prerelease.

## Who is affected

- **New applications.** `bun add @venizia/ardor` resolves the stable line, and `^0.1.1` no longer accepts a prerelease.
- **Applications on `next`.** Nothing to change. Move a `^0.1.1-x` range to `^0.1.1` when convenient.
- **Every application.** The IGNIS peers are the stable `^0.2.0`, as in 2026-09-24.
