# Changelog - 2026-10-17

## ARDOR's agent tooling moves to VULCAN 0.2.0-1

<Badge type="tip" text="Enhancement" />

**In one line.** ARDOR pins `@venizia/vulcan` 0.2.0-1, which reads `.configs/vulcan.config.ts` for every knowledge and atlas command, so ARDOR keeps no generator of its own.

```bash
bun install
make vulcan-sync     # every line reads unchanged on the second run
make vulcan-doctor   # vulcan doctor: OK
```

## What changed

- **okf reads ARDOR's config.** `make okf-gen` renders the reference pages from the `okf` section of the config. ARDOR's two page renderers live in `.agents/okf/`, and `.agents/knowledge-tools/` and `scripts/vulcan-bridge.ts` are gone. CI checks the bundle with `make okf-check-strict`.
- **The atlas computes symbols and releases.** Symbols come from the built `.d.ts` and releases from the git tags, each time the atlas is asked. `reference/symbols.json` and `reference/releases.json` are no longer committed, and `scripts/release.ts` no longer refreshes them after a release. `make atlas-symbols` and `make atlas-releases` print what the atlas reads.
- **Every changelog entry names its packages.** Each entry declares `packages:` in its frontmatter. An entry about the repository tooling declares `packages: []`.
- **The atlas also serves IGNIS.** `atlas.sources` adds IGNIS's `develop` branch, so one ARDOR atlas session searches both frameworks. When GitHub is unreachable, the atlas serves ARDOR alone and names IGNIS as unavailable.
- **The minimap shape prints with the rules.** VULCAN's session digest prints the minimap block of `.agents/rules.md`, so ARDOR's `.agents/hooks/minimap.ts` is gone.

## Who is affected

- **Applications that use ARDOR.** No action needed. The published packages and their API are unchanged.
- **Contributors to the ARDOR repository.**
  - Run `bun install`, then `make vulcan-sync`, after you pull.
  - Run `bun x vulcan sync --prune` once. It removes the stale minimap hook entry from your `.claude/settings.json`.
  - Add `packages:` to every new changelog entry.
